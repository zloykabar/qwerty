# Джарвис 3.0 — заметки для агента

Русскоязычный голосовой ассистент под Windows 10/11. Распространяется архивом,
настраивается `install.ps1` (через `INSTALL_JARVIS.bat`), как Python-пакет не ставится.

## Команды

```bash
python -m unittest discover -s tests -v   # тесты логики (20 шт., кроссплатформенные)
python -m pyflakes .                      # статический анализ; должен быть чистым
python -m compileall -q .                 # проверка синтаксиса всех модулей
```

Тесты работают на Linux: Windows-специфика (реестр, win32, звук) подменена заглушками
в `tests/test_core.py` (`FakeCore`, `FakeBrowser`). Реальный запуск — только на Windows.

## Устройство

- `jarvis.py` — точка входа, окно pywebview, поток команд, `_single_instance()`, `_run_steps()`.
- `core/` — `registry.py` (реестр действий + уровни риска), `actions.py` (каталог действий),
  `safety.py` (разрешённые папки, запуск процессов), `scenario.py` (цепочки), `nlu.py` (русский NLU),
  `paths.py` (BASE_DIR/LOG_DIR, `icon_path()`), `logsetup.py` (логи с ротацией).
- `config/*.json` — правятся без Python: фразы, синонимы, города, алиасы программ, сценарии, безопасность.
- `logs/` — `assistant.log` и `jarvis.log`; в git не попадают.

## Инварианты, которые легко сломать

- **Никакого `shell=True`.** Все процессы запускаются списком аргументов (`core/safety.py:popen`,
  `jarvis.py:_run_cmd`). Иначе подменённый `config.json` = выполнение произвольной команды.
- **`ctypes` и `GetLastError`.** Для чтения кода ошибки нужен `WinDLL(..., use_last_error=True)`
  и `ctypes.get_last_error()`: обычный `windll` затирает ошибку промежуточными вызовами.
- **Уровни риска.** `risk="confirm"` и `risk="danger"` оба требуют голосового «да»
  (`core/registry.py`). Таймаут действия увеличивается на `confirm_timeout + 5`.
- **Иконка — одна.** Канонический путь `assets/app.ico` (`brand.py` генерирует, `core/paths.py` ищет).
- **Формат файлов Windows.** `.ps1`/`.bat`/`.txt` — CRLF (иногда с BOM), задано в `.gitattributes`.
  При правке этих файлов сохраняйте переводы строк, иначе ломается diff и `cmd.exe`/PowerShell.

## Установщик (`install.ps1`)

Артефакты с фиксированной версией (Python embed, модель Vosk) проверяются по SHA256 из таблицы `$SHA`.
Установщики по «плавающим» ссылкам (Ollama, VC++, WebView2) — по подписи Authenticode (`$TRUSTED_SIGNERS`).
Тип файла определяется по конечному имени, а не по временному `*.part`.
Хэши при обновлении версий пересчитывать: `curl -sL <url> | sha256sum`.

## Смешанная речь ru-en и быстрый старт (добавлено)

- Распознавание: `whisper_worker.py` работает на `faster-whisper` (CTranslate2, int8 на CPU) —
  модель `small` грузится за ~5 с вместо ~60 с у прежнего `transformers`+torch. Если
  `faster-whisper` не установлен, автоматически откатывается на `transformers`.
- Язык и второй проход задаются в `config.json`: `asr_language` (auto | ru | en | ru-en),
  `asr_second_pass`. При `auto` — один проход с автоопределением; если модель сомневается,
  делается ещё по одному проходу (ru и en), выбирается лучший по уверенности и совпадению с hotwords.
- Правки распознавания названий — `config/asr_corrections.json` (ключ — как услышала модель,
  значение — как правильно). Значения с латиницей автоматически попадают в подсказку Whisper.
  Применяются в `Core._fix_asr()` для всех движков, включая Vosk.
- Старт не блокируется загрузкой Whisper: `whisper_start_wait` (по умолчанию 6 с) — ассистент
  начинает слушать сразу и переключается на Whisper, когда тот готов.
- Фильтр галлюцинаций `stt.clean_text`: отбрасывает повторы одного слова («Windows, Windows…»),
  которые faster-whisper выдаёт на шуме.
- Логика языка/правок вынесена в `core/asr_fix.py` (без тяжёлых зависимостей, покрыта тестами).
