# Тест-план Джарвиса 3.0 (проверять на своём ПК)

Перед началом: запусти Джарвиса, дождись в окне «✓ слух ✓ голос ✓ мозг ✓ программы». Для пунктов с браузером нужен Chrome или Edge.
Лог всего происходящего: `logs/assistant.log`. Замеры старта: строки `[старт] ...`.

| № | Скажи | Ожидаемая реакция |
|---|-------|-------------------|
| 1 | «Джарвис, открой ютуб» ×10 подряд | 10 разных по формулировке подтверждений, ютуб открывается |
| 2 | «открой ютуб, включи видео про котов, перемотай на 3 минуты и закрой ютуб» | Браузер Джарвиса открывает YouTube, находит и запускает видео, перематывает на 3:00, закрывает вкладку. После каждого шага короткая реплика, в конце «Всё выполнено» |
| 3 | «открой ютуб, включи нужное видео, перемотай на 1:30 и закрой ютуб» | Ровно ОДИН вопрос «Какое видео включить?». После ответа сценарий идёт до конца |
| 4 | Во время №2 скажи «стоп», затем «дальше» | Пауза после текущего шага, потом продолжение |
| 5 | Во время №2 скажи «отмена» | Сценарий остановлен, открытая вкладка закрыта |
| 6 | Отключи интернет, повтори №2, затем включи и скажи «повтори сценарий» | Сбой на шаге с видео, безопасное завершение; повтор не открывает YouTube заново, а продолжает с неудавшегося шага |
| 7 | «какая погода в уфе» / «погода Уфа» / «Уфе погода» / «сколько градусов в Уфе» | Везде погода для города Уфа |
| 8 | «погода в питере», «погода до казани» | Санкт-Петербург, Казань |
| 9 | «открой хром», «открой кроум», «open Chrome», «запусти visual studio code» | Открывается Chrome / Chrome / Chrome / VS Code (с Whisper надёжнее, на Vosk работает только русское произношение) |
| 10 | «открой хромм» (с ошибкой) | Вопрос «Ты имел в виду Chrome?», на «да» открывается |
| 11 | «найди файл отчёт и создай папку Отчёты на рабочем столе» | Если файла нет, честно скажет «ничего не нашёл» и завершит безопасно; папка не создаётся (шаг 2 не выполняется после сбоя шага 1). Отдельно «создай папку Отчёты на рабочем столе» создаёт папку |
| 12 | «удали всё» | Спрашивает подтверждение с точным описанием; без «да» ничего не удаляется; при «да» очищается ТОЛЬКО Documents\Jarvis, в Корзину |
| 13 | «выключи компьютер», потом «нет» | Ничего не происходит. На «да»: выключение через 30 секунд, «отмени выключение» отменяет |
| 14 | «добавь команду» → «чат» → «открыть программу» → «телеграм» → «нет» → «пропусти» → «да» | Команда сохранена, «Джарвис, чат» открывает Telegram без перезапуска |
| 15 | «добавь команду» → «открой» | «Фраза занята: это встроенная команда», спрашивает про переопределение |
| 16 | «добавь команду» → «рисовать» → «сварить борщ» | Честно: такого действия нет, предлагает ближайшие |
| 17 | «добавь несколько команд» → «когда я говорю чат, открой телеграм, следующая, когда я говорю считать, открой калькулятор, всё» → «да» | Обе команды сохранены |
| 18 | «мои команды», «покажи шаги команды чат», «измени команду чат», «удали команду чат» | Список, шаги, правка, удаление после «да» |
| 19 | «пошути» ×5, «ещё» ×3 | Разные шутки без повторов |
| 20 | «факт», «про космос», «расскажи страшилку», «расскажи подробнее» | Факт, факт про космос, короткая озвучка + полный текст в чате, затем чтение целиком |
| 21 | «загадай загадку» → неверный ответ → «подсказка» → «сдаюсь» | Подсказка по первой букве, затем правильный ответ |
| 22 | «поиграем» → «угадай число» | Игра «больше/меньше», 7 попыток |
| 23 | «камень ножницы бумага», «орёл или решка», «игра в слова» | Игры работают |
| 24 | «слушай Джарвис а скажи сколько времени» | Время называется словами («четырнадцать тридцать») |
| 25 | Негатив: «открой несуществующую программу» | «Не нашёл программу…», приложение не падает |
| 26 | Негатив: «перемотай на» без времени, когда видео не открыто | Вопрос про время или сообщение «на странице нет видео», не падает |
| 27 | Негатив: «создай папку» (без имени) | Один вопрос про имя папки |
| 28 | Иконка | Своя иконка в окне, на панели задач, в трее и в свойствах Assistant.exe. Иконки Python нигде нет |
| 29 | «Яндекс музыка», «YouTube», «Terraria», «Roblox» (по одному, чётко) | Названия распознаются с первого раза, без повторов фразы |
| 30 | «Джарвис, открой ютуб» → «Джарвис, запусти террарию» → «Джарвис, включи роблокс» | Смешанные русско-английские фразы понимаются, открывается нужное |
| 31 | «open Chrome», «launch YouTube», «start Terraria» (полностью по-английски) | Команда понимается, приложение открывается |
| 32 | Скорость старта | Первый кадр «готово» от распознавателя за 5–10 с (было ~60). В logs/assistant.log строки `[старт]`: окно появляется раньше, чем «Whisper загружен» |
| 33 | Негатив: «открой абракадабру непонятную» | Честное «не нашёл программу», без падения |
| 34 | Шум/тишина возле микрофона 10 с | Никаких команд не срабатывает, повторов «Windows, Windows…» не слышно |
